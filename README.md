🌊 Ocean Intelligence Platform

An interactive ocean intelligence dashboard for exploring marine ecosystems, environmental changes, and biodiversity patterns across the Arabian Sea.

📌 Overview

The Ocean Intelligence Platform brings together oceanographic and marine biodiversity indicators in a unified dashboard. It helps users explore environmental trends, examine relationships between ecological variables, identify potential anomalies, and generate data-driven insights through interactive visualizations.

The platform focuses on the Arabian Sea, including regional analysis of the Oman Coast, Central Arabian Sea, and western Indian coastal shelf.

✨ Features

Environmental Monitoring: Analyze Sea Surface Temperature (SST), salinity, ocean currents, and ocean colour indicators.

Marine Biodiversity Analysis: Explore fisheries catch, larvae counts, and cetacean sightings.

Interactive Geospatial Map: Visualize regional boundaries and ecological hotspots using Leaflet.

Time-Series Visualization: Examine environmental and biological trends over selected periods.

Correlation Heatmap: Investigate relationships between environmental and biological variables.

Anomaly Detection: Identify unusual observations and potential ecological contradictions using statistical thresholds.

AI-Driven Insights: Present data-based summaries of environmental conditions, biodiversity shifts, and anomalies.

Regional Comparison: Explore the Oman Upwelling Zone, Central Deep Basin, Eastern Shelf, and aggregated regional data.

Yearly Reports: View summary statistics and year-over-year comparisons.

2027 Outlook: Explore the platform's ecological prediction and forecasting section.

🛠️ Technologies Used

HTML, CSS and JavaScript — User interface and dashboard logic

Leaflet.js — Interactive maps

ApexCharts.js — Charts, heatmaps, time-series graphs, and bubble visualizations

JSON — Dashboard data exchange

Python — Data preparation and processing, where implemented
