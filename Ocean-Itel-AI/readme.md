# Ocean Intel 🌊

An interactive ocean intelligence dashboard for exploring oceanographic data, marine biodiversity, fisheries trends, and environmental anomalies.

## Features
- Interactive ocean data dashboard
- Marine environmental indicators and visualizations
- Regional ocean data exploration
- Correlation analysis
- Statistical anomaly detection and alerts
- Marine biodiversity insights
- Data processing using Python

## Tech Stack
- Python
- HTML, CSS, JavaScript
- Leaflet.js
- ApexCharts
- JSON

## Run Locally

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Navigate to the project folder.
3. Start the local server:
   ```bash
   python -m http.server 8000
   ```
4. Open `http://localhost:8000` in your browser.

## Project Purpose

To make oceanographic and marine biodiversity data easier to explore through interactive visualizations and data-driven insights.
